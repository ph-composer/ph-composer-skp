# Engineering context

Use these documents when changing PH-Composer or working with its code.

| Task | Owning document |
| --- | --- |
| Name a record, quantity, relationship or UI concept | [Project terminology](UBIQUITOUS_LANGUAGE.md) |
| Place code in the right layer and follow repository conventions | [Coding standards](CODING_STANDARDS.md) |
| Work with registration, outcomes, revisions, records or export schemas | [Core contracts](CONTRACTS.md) |
| Add a feature, provider, view, tool or exporter | [Contributor architecture](EXTENSIBILITY.md) |
| Change SketchUp transactions, panel behavior, units or the runtime | [Technical architecture](TECH_STACK.md) |
| Resolve an observed SketchUp behavior | [Measured host behavior](SKETCHUP_HOST_BEHAVIOR.md) |
| Choose a control route for a native acceptance case | [Native control capabilities](NATIVE_CONTROL_CAPABILITIES.md) |
| Change agent discovery, reads, writes or access grants | [Agent interface](AGENT_INTERFACE.md) |
