# Security policy

## Reporting a vulnerability

The project designates GitHub private vulnerability reporting. That option is currently disabled.
Check the repository's [Security page](https://github.com/ph-composer/ph-composer-skp/security)
for the private reporting option. Keep vulnerability details out of public issues.

Include the PH-Composer build from Help & Diagnostics, your SketchUp version and platform,
and the steps that demonstrate the problem. Say whether it involves an agent token or library.
Use a synthetic model and omit tokens and client data.

## Scope and supported builds

This policy covers the extension package, including its dialogs, local agent connection,
export runtime and approved file access. The project supports development builds from `main`
until the first release. After that, it supports the latest release.

## Response

The maintainers aim to acknowledge private reports within seven days. The next release records
the fix or the decision on a confirmed issue.
