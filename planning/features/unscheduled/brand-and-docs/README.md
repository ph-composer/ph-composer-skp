# Brand and public documentation

DATE: 2026-11-25
STATUS: Scoped. Brand direction chosen in a prototyping session on 2026-11-25; plan drafted the same day. Nothing is implemented and no stage is authorized.
AUTHOR: Ed May, BLDGTYP, with Claude
ISSUE: none (local planning draft; open one when Ed authorizes the first stage)

A brand for PH-Composer as a suite, a variant of it for PH-Composer for SketchUp, and the public
documentation the project needs before a December 2026 soft beta. PH-Composer gets its own landing
page and docs site. The PH-Tools sites link to it, but PH-Composer is not presented as part of
PH-Tools.

## Read order

1. [DECISIONS.md](DECISIONS.md): what was chosen, what was tried and dropped, and what is still open.
2. [PLAN.md](PLAN.md): the stages, what the December beta needs, and the documentation map.
3. [STATUS.md](STATUS.md): current state and the next step.
4. [mockups/](mockups/README.md): the canvas source, the mark generator and the generated marks.

## Scope

In scope:

- The mark, its small-size and per-product variants, and the splash illustration.
- Colour and type for the web, docs and tutorials.
- How the brand appears inside SketchUp: icons, splash, and the panel's colours.
- A landing page and a docs site of PH-Composer's own.
- The documentation suite, planned on the [Diátaxis](https://diataxis.fr/) frame: tutorials,
  how-to guides, reference and explanation.
- A video tutorial, after the beta interface settles.
- An update to the PH-Composer Design System once the panel changes land.

Out of scope:

- Any change to what the extension does.
- The PH-Tools sites themselves, apart from adding links.
- Branding for products that do not exist yet. The system leaves room for them and stops there.

## Why this packet sits here

The brand belongs to the suite, and this repository is one product in it. The packet lives here
because this is the only PH-Composer repository with a `planning/` tree. Where the brand assets
and the site live in the end is an open question in [DECISIONS.md](DECISIONS.md#open).
