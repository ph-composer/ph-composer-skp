Wheel zoom in the HtmlDialog runs near 40 frames a second, below the 60 Hz the browser tool showed: a
scale change redraws the 33,608-point border paths with non-scaling strokes, where a pan only translates
them. It is usable; whether it feels so is in Ed's pass.

When the warning appears the dialog grows by it and re-centres, so the map moves up about 37 px under the
pointer at 1280 x 800. Also in Ed's pass.

A thousand-marker run tried in part A got no animation frame (the panel's page was hidden then) and was
run in part B with the panel on screen.
