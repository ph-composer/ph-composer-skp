# PH-Composer UI Reference Patterns

All paths below are relative to `src/ph_composer/html/`. The UI kit registers modules with `PhComposerUI.define` and uses the `phc-` class prefix. Reinspect the live file before reusing or extracting a shared primitive.

## Shared Primitives

- **Core facade (`workspace.js`):** Exposes `ui` over focused modules: `dom.js` (elements, `svg`, `commandButton`, `memoPaint`, `paintChip`), `icons.js` (Lucide registry; throws on unknown names), `overlay.js` (`Bubble`, `ActionMenu`, `formDialog`, `floatingNotice`, tooltips), `table.js`, and `view_controls.js` (filter, group, order, group headings, optional `guard`/`refused`).
- **Panel shell (`panel.js`, `request.js`, `snapshot.js`, `selection_bar.js`):** Owns the snapshot reducer, tabs, `panel.notify(message, tone, action)`, `panel.navigationGuard(name, guard)`, and `panel.navigate(tab, intent)`. Pane regions: `main` (work surface), `inspector` (single column chosen by tier `tool` > `selection` > `record` > `ambient`; drops below `<900px`; `"hold"` keeps active drafts), `tools` (control-row end), `actions` (page-header `.phc-toolbar`). Panes needing a fixed width either keep an always-on `ambient` hint (`order: 1000`) or omit the inspector and use `selection_bar.js`.
- **Stylesheet layering (`index.html`):** Shared kit sheets (`base.css`, `overlay.css`, `drawing_dimensions.css`, `shell.css`, `table.css`, `source_cards.css`, `outline_map.css`) load before feature sheets (`library/library.css`, `features/*/*.css`). Feature overrides must carry the feature's scope class so specificity, not link order, governs. `--page-gutter` in `base.css` is the single horizontal inset; region rules (such as subtabs) bleed to the panel edge.
- **Page header (`page_header.js`):** `ui.pageHeader({ title, actions, primary })` is the sole page heading (no caption or count—counts live in the control row). `setTitle` renames in place. Detached sessions (e.g. `features/windows/install_editor.js`) use the same header with a breadcrumb; Cancel/Save sit with the work.
- **Subtabs & pill rows (`subtabs.js`, `pill_row.js`, `base.css`):** `subtabs.js` supports `guard`, `refused(reason, nextId)`, and `reselected(id)`. Focused inputs block tab switches only while edited (`field.typed` or value changed from focus). `pill_row.js` selects peer tables inside a subtab with the same guard contract (first used in `features/mechanical/systems.js`, stored as `table_view`).
- **Overlays, dialogs & notices (`overlay.js`, `overlay.css`, `record_form.js`, `inventory_forms.js`):**
  - `formDialog(className, onCancel)` is the single modal (top-right `.phc-dialog-close` matches Escape/Cancel and restores focus). `record_form.js` handles container, title, submit/Cancel order, status line, and single-flight requests (`RecordForm.required` marks required fields). `inventory_forms.js` provides `DuplicateForm` and `ReplacementForm` (`allowClear` can be a function of the record; another feature adds the uses it knows with `contributeUsage(section, usage(state, id, choice))`, listed after the owner's own and worded for the replacement chosen so far). `ColorForm` is the anchored colour picker behind every `colorCell`; a kind whose cleared colour returns to a default passes `{ defaultColor(record) }`, and the picker then shows **Reset to default** (a swatch of that colour) while the stored colour differs, sending `color: null` through the same update.
  - `ui.tooltip(node, text)` owns hover/focus hints above bubbles and dialogs; never set native `title` attributes or SVG `<title>` children.
  - `ui.reasonButton(action, reason)` places an alert icon ("Why `<action>` is unavailable") beside a blocked action, opening an anchored bubble.
  - `notice.show` takes `tone`: `info` (default, white), `success` (white + check, `SUCCESS_MS` = 3 s, held on hover/focus), `warning` (yellow), `error` (red). Host context-menu completions use `:success`.
- **Tables & inventories (`table.js`, `table.css`, `inventory.js`, `inventory_grid.js`, `column_menu.js`):**
  - Quiet grid: row hairlines, header-only column separators, full-row hover wash, sticky Actions/Hierarchy columns, mouse/keyboard column resize (double-click resets).
  - `tree: true` styles top-level rows as group headings; `expandable(row)` reserves chevron space on leaf rows; `revealRowActions` hides unchecked boxes and row icons until hover/focus (or until any row is checked).
  - Two-band headers (`headerActions(field)`): 34 px label band + 28 px action band across all columns when present; elided labels keep full text in tooltips.
  - Control row (`view_controls.js`): filter field, Group by, Order by + direction (hidden when `columnSort: true`, which moves sort/filter into `column_menu.js`), Collapse/Expand all icon toggle (Lucide `copy-minus` / `copy-plus`), muted count, help button, range-fill tools (reserved slot), and tab settings (`Inventory` `settings` / `optionalColumns` / `hiddenColumns`). No row-number column.
  - Row actions: `disabled` hides icon (keeps slot); `unavailable: "<reason>"` stays visible in quiet ink with tooltip; `pressed` marks running tools. Held cell drafts place `.phc-cell-cancel` inside the cell's right edge so row height stays fixed.
- **Chips, enums & units (`dom.js`, `table.css`, `unit_field.js`, `units.js`, `unit_preferences.js`, `fields.js`):**
  - `select.phc-enum-cell` (24 px pill with inset chevron; `--category-fill` for semantic colors; `face_words.fill(field, value)` for Honeybee face/boundary hues). Read-only pills use `span.phc-enum-pill` with lock/hatch and tooltip. Dark chips flip text and chevron to light via `paintChip`.
  - Columns whose header carries a unit show bare numbers via `units.format(..., { showUnit: false })`. Missing values show amber `?` pills with tooltips naming what to set.
- **Drawing dimensions (`drawing_dimensions.js`, `drawing_dimensions.css`):** `ui.dimensionRule` (light rule, boundary dots, short extensions), `ui.dimensionValue`, and `ui.inlineDimension` (in-place `UnitField` swap). Drawing bubbles use `detachedTrigger: true` mounted outside scrollports/transforms; center labels with layout rather than transforms.
- **Source cards (`source_cards.js`, `source_cards.css`):** Vertical list of state-bearing subject cards beside a pane (neutral, `ok` teal, `warning` amber via `data-tone`; `planned` cards read-only). Degrades to a select `<700px`. Used in Climate (`features/climate/`).
- **Outline map (`outline_map.js`, `outline_map.css`, `map_projection.js`, `map_borders.js`):** Pan/zoom world + US/Canada outline map with fixed-size markers, distance rings, and pin; always paired with non-map inputs. Used in Set Location (`features/climate/set_location.js`).

## Accepted Screen Patterns

- **Zones / Geometry (`features/zones/overview.js`, `zone_cells.js`, `zones.css`, `attached_zone_assignment.js`):** Full-width tree table, no inspector. Unclassified Faces group under `"N unclassified Faces"` per Zone (auto-open ≤10, paginated at 50). Checkboxes drive the floating selection bar (batch Type/Boundary/Assembly, Checked-Zone Solve for ≥2 fully checked Zones). Creation stays in SketchUp's native context menu. Attached-zone creation opens `formDialog` from the boundary chip.
- **Building Segment headings (`features/zones/segment_rows.js`):** Every Zone view groups Zones under non-selectable Segment heading rows (Model Segments by name, unadopted Zones, muted "No Building Segment" last if non-empty), carrying contributed tags, view-specific sums (`segmentSums`), hover-revealed Settings/Delete, and inline-rename `+ New Building Segment`. Segment settings use `formDialog` with sections registered via `panel.segmentSettingsSection`.
- **Zones / Spaces (`features/spaces/view.js`, `cells.js`, `actions.js`, `selection.js`, `create_review.js`):** Table-first Zone view sharing Segment headings, inline cell edits, range fill, and floating selection bar.
- **Zones / Programs (`features/programs/zones_view.js`, `zones_cells.js`, `zones_selection.js`, `occupancy.js`, `programs.css`):** Third Zone view with immediate one-Undo edits, muted italic inherited defaults, amber `?` for uncomputable values, **Lock bubble** for single-dwelling Segment overrides (links to Segment settings), and **Dwelling bubble** (anchored select + inline Units/Bedrooms fields).
- **Column-scoped Face painting & Colour-by (`features/zones/classify.js`, `sections/colour_by.js`):** Paint icons sit beside values in Type, Boundary, and Assembly column menus (no separate picker). Active paint leases the matching Colour-by mode (`ColourBy::Lease`) and restores the prior mode on stop unless changed. Column header palette toggles (`HeaderToggle`) control Colour-by; swatches live in each column's Show checklist (no panel legend strip).
- **Assembly Builder (`features/assemblies/editor.js`, `canvas.js`, `stage.js`, `inspector.js`, `layer_tools.js`, `layer_drag.js`, `assembly.css`):** Centered floating toolbar above canvas; proximity edge-insert control (one at a time, named by visual result, hides during Material drag); inline thickness/width editing; hover-revealed Layer gear + 6-dot drag grip (6 px threshold, red boundary drop line, atomic Undo; membrane thickness drafts stay visible with reason until Escape); teal selection hatch + `-1px` centered outline stacked below insertion cues.
- **Window Types & Installs (`features/windows/editor.js`, `canvas.js`, `placement.js`, `install_editor.js`, `windows.css`):** Grouped drawing toolbar (View, Window Type, Assign, selection edits) with `select.phc-choice-pill`; Place tool anchor picker as 3×3 grid beside Place; Types rail with hover-overlay actions; detached Installs editor with teal solid/dashed edge states, perimeter labels, and bottom-pinned Cancel/Save.
- **Library & Sidebar (`library/section.js`, `sidebar.js`, `rows.js`, `setup.js`, `library.css`, `features/windows/inventory.js`):** Provider-agnostic collapsible sidebar (right side in Builders; hides local list when `besideTable`; folds groups >20 records; category + A–Z/Z–A view pills). Setup dialog leads with File/Folder choice cards when empty and uses Done (immediate apply). Programs' one-record editor (`features/programs/record_page.js`, `program_editor.js`) pairs the sidebar with accordion load cards.
- **Thermal Bridges & Viewport Tool Bars (`features/thermal_bridges/edge_tool.js`, `assign_bar.js`, `thermal_bridges.css`):** Types + Schedule subtabs; always-present assign bar above Types with selection count, type/quantity, Assign/Clear, and persistent pressed `"Assign by clicking"` toggle (+ Stop) that re-arms when bar values change. Schedule refreshes on demand with `"Changed since read"`, row Locate, and `detachedTrigger` findings bubbles.
- **Mechanical (`features/mechanical/systems.js`, `equipment_table.js`, `serves.js`, `optional_values.js`, `mechanical.css`):** System subtabs with `pill_row.js` sub-views over shared `EquipmentTable` (Tag pinned beside Actions). `serves.js` Zone picker bubble mounted outside table scroller (grouped by Segment, explicit conflict replacement); `optional_values.js` chevron bubble for off-row unit fields; destructive type changes open `formDialog` naming discarded values.
- **Export Readiness (`sections/export.js`):** Single status line + findings grouped by cause under "Before exporting" and "Worth checking", with Locate and `"Open <tab>"` (`panel.workedOn`). Active export locks tabs via `panel.navigationGuard` and keeps progress + Cancel visible.

## Shared Visual Semantics

| Token | Usage |
| --- | --- |
| `--interaction-highlight` | Interactive borders, selected controls, active sidebar rows, selected drawing elements |
| `--interaction-highlight-hover` | Stronger hover and active emphasis |
| `--interaction-highlight-tint` | Low-contrast selected backgrounds (sidebar rows, pressed choices, selected drawing fill) |
| `--drawing-highlight` | Drawing hover, keyboard focus, insertion geometry, drop targets (never selection) |
| `--drawing-highlight-halo` | Focused or hovered drawing affordance halo |
| `--line`, `--muted`, `--surface` | Neutral structure and hierarchy |

Do not create feature-local substitutes unless evidence shows the shared token is wrong app-wide.
